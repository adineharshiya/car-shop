# 🏎️ LuxeAuto | Black & Gold Luxury Car Marketplace

A premium luxury car marketplace with an elegant black & gold design. Users can browse, search, filter, and purchase luxury vehicles. Features include user authentication, shopping cart, order history, and an admin panel for managing inventory and viewing sales analytics.

![LuxeAuto Preview](https://via.placeholder.com/800x400?text=LuxeAuto+Preview)

---

## ✨ Features

### 👤 User Features
- **User Authentication** – Register / Login system with session management
- **Browse Cars** – View all available luxury vehicles with images and details
- **Search & Filter** – Search by name/brand and filter by brand
- **Sorting** – Sort by price (low to high / high to low)
- **Car Details** – View detailed specs including engine, horsepower, and description
- **Shopping Cart** – Add/remove items, view total price
- **Checkout** – Place orders (simulated showroom pickup)
- **Order History** – View past purchases and total spent
- **Profile Management** – Edit email and password

### 👑 Admin Features (Login: `admin` / `admin123`)
- **Dashboard** – View sales statistics (today, week, month, all-time)
- **Best Sellers** – See most popular cars by order count
- **Manage Cars** – Add, edit, or delete car listings
- **Real-time Updates** – Changes reflect immediately for all users

### 🎨 UI/UX
- Responsive design (mobile, tablet, desktop)
- Swiper.js image slider on homepage
- Animated feature cards and statistics
- SweetAlert2 notifications
- Font Awesome icons throughout
